## Tuyến API Concepts
Các ga và khái niệm nằm trong `content/series/api-concepts.md`. Thứ tự học: ga 1 → 6.

## Ngoài tuyến API, nên học sau
- Compression (gzip, br) cho response API
- Batching request
- Observability cho API: log, metric, trace
- Deprecation: ngừng hỗ trợ một phiên bản API mà không làm hỏng client
