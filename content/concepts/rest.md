**REST** là phong cách kiến trúc Roy Fielding mô tả năm 2000: client-server, stateless, có thể cache, giao diện thống nhất, phân lớp. Trong thực tế, REST API nghĩa là mỗi tài nguyên có URL, dùng đúng method và status code. Ưu điểm lớn nhất: ai cũng gọi được, cache và proxy HTTP hiểu sẵn.
