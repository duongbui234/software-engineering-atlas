An **endpoint** is a *method + path* pair, for example `POST /api/v1/checkout`; the same path with a different method is a different endpoint. I name paths with nouns (resources) and let the method be the verb, using path params for identity and query params for filters.

Read more in [[en/posts/2026-11-18-api-foundations|API Foundations]].
