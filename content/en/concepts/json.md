**JSON** has only string, number, boolean, null, object and array. There is no date type and no decimal, and numbers are usually parsed as 64-bit floats, so money and large ids should be sent as strings, and dates as ISO 8601.

Read more in [[en/posts/2026-11-18-api-foundations|API Foundations]].
