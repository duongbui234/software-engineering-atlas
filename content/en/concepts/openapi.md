**OpenAPI** describes endpoints, parameters, request/response schemas, status codes and authentication in one YAML/JSON file (version 3.1 uses JSON Schema). From that one file you can generate docs, typed clients, mock servers, validators and contract tests. The spec must be generated from the code, or the code checked against the spec in CI; otherwise they drift apart.

Read more in [[en/posts/2026-11-18-api-architecture|API Architecture and Operations]].
