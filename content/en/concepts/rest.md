**REST** is the architectural style Roy Fielding described in 2000: client-server, stateless, cacheable, uniform interface, layered system. In practice, a REST API means every resource has a URL and you use the right methods and status codes. Its biggest advantage: anyone can call it, and HTTP caches and proxies already understand it.
